# ✅ Release checklist — SkillSpring Little Explorers

## Device / game checks
- [ ] iPad Safari: home page fits, world cards are easy to tap; no accidental horizontal scrolling.
- [ ] Android tablet: no overlapped buttons in portrait or landscape.
- [ ] Small phone: world cards and quiz choices remain legible.
- [ ] Desktop Chrome: keyboard Tab/Enter works for every option.
- [ ] With sound on, opening a world speaks the prompt (speaker toggle + Hear again).
- [ ] With sound off, no spoken prompt starts.
- [ ] Wrong answer: supportive feedback; after repeated mistakes the correct choice is highlighted.
- [ ] Correct answer: a star is earned exactly once, Next button appears.
- [ ] Completing four questions leads to a finish screen and an earned sticker.
- [ ] Replaying a world earns a second sticker, then the third on the third play.
- [ ] Refresh preserves stars, stickers, and world level on this device.
- [ ] For grown-ups → Reset removes saved progress after confirmation.
- [ ] After first online load, load the page with network disabled and check the offline shell.

## Competition / quality checks
- [ ] Students personally understand and can explain the learning algorithm.
- [ ] Team added meaningful original code and can identify it.
- [ ] Team verified latest official Congressional App Challenge district, submission, and AI-disclosure rules.
- [ ] Test with a grown-up and get permission before involving any children.
- [ ] Avoid filming identifiable children or publishing their information without parental permission.
- [ ] Demo video shows an actual interaction, a code explanation, and how the app helps kids.
- [ ] No misleading claims about educational outcomes.
